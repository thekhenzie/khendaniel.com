Building in action

31 August 2018

Since Monday, I'm working on my blogsite. At first, I don't know how since I'm new to it. I've found several tutorials about creating blogsites using Jekyll and hosting it through Github Pages. Luckily, I found this blogsite which uses Metalsmith as the framework for my blog.

After tinkering and experimenting, I immediately host it to Github Pages. I also use a custom domain bought at GoDaddy for just a dollar. Actually, I have used Github pages before so I knew how to host one. While I'm busy creating my blogsite, I hosted a coming soon page like this. I also got stucked on making my website running on SSL. Fortunately, Github Pages automatically provided the users with it.

Its kinda funny because I set my deadline before October, but I actually finished it by the end of August. I guess that I'm just too productive then. 😅
