Actually, I have used Github pages before so I knew how to host one. While I'm busy creating my blogsite, I hosted a coming soon page like this. I also got stucked on making my website running on SSL. Fortunately, Github Pages automatically provided the users with it.

Its kinda funny because I set my deadline before October, but I actually finished it by the end of August. I guess that I'm just too productive then. 😅
